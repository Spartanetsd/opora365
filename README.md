# ОПОРА · Мій день

Перша частина застосунку «ОПОРА» для iPhone. Встановлюється на початковий екран і працює без інтернету.

- **Ранок** — бажаний час прибуття, транспорт, дорога і запас → час виходу та підйому. Режим ранкової підготовки з відліком, кроками, пунктами перевірки й режимом «Часу обмаль» (критичні перевірки не скорочуються).
- **Справи** — швидке додавання, пріоритети «Обов’язково сьогодні / Важливо / Можна пізніше», прострочене зверху, «Перенести» без дублікатів, три головні справи на екрані «Сьогодні».
- **Обов’язкові** — справи, що щодня залишаються на виду, доки їх не позначено виконаними; лічильник днів і необов’язковий строк.

Усі дані зберігаються лише на iPhone (IndexedDB + резервна копія в localStorage) і не зникають після закриття застосунку. Жодних серверів, входу, аналітики чи сторонніх бібліотек.

## Файли

Усі файли лежать в одній папці, без підпапок — їх можна завантажити на GitHub прямо з iPhone.

| Файл | Призначення |
|---|---|
| `index.html` | сторінка застосунку |
| `styles.css` | оформлення, світла й темна теми |
| `app.js` | ядро: стан, вкладки, оновлення часу, офлайн |
| `logic.js` | розрахунки без інтерфейсу (час виходу, пріоритети, перенесення, перевірка даних) |
| `store.js` | збереження на пристрої, резервні копії |
| `ui.js` | іконки, нижні панелі, повідомлення |
| `view-today.js`, `view-morning.js`, `view-tasks.js`, `view-musts.js`, `view-settings.js` | екрани |
| `sw.js` | Service Worker — робота без інтернету |
| `manifest.webmanifest`, `icon-*.png` | встановлення на початковий екран |
| `tests.js`, `tests.html` | тести логіки (у браузері або Node) |
| `package.json` | команди для комп’ютера (необов’язково) |

## Публікація на GitHub Pages з iPhone

1. Розпакуйте архів у «Файлах» (торкніться його — з’явиться папка).
2. На github.com створіть **публічний** репозиторій, наприклад `opora`.
3. «Add file» → «Upload files» → оберіть **усі файли** з розпакованої папки → «Commit changes».
4. «Settings» → «Pages» → «Source: Deploy from a branch» → гілка `main`, папка `/ (root)` → «Save».
5. За 1–2 хвилини застосунок буде за адресою `https://ВАШ-ЛОГІН.github.io/opora/`.

Шляхи у проєкті відносні, тож назва репозиторію може бути будь-якою.

## Встановлення на iPhone

1. Відкрийте адресу застосунку в **Safari**.
2. «Поділитися» → «На початковий екран».
3. Переконайтеся, що увімкнено «Відкривати як вебзастосунок», → «Додати».
4. Запускайте ОПОРА **з іконки**. Перший запуск — з інтернетом, далі застосунок відкривається й офлайн.

> Сховище Safari і встановленого застосунку на iOS окремі. Справи, додані у вкладці Safari, не з’являться в застосунку з іконки — починайте роботу одразу з іконки.

## Оновлення

1. Замініть змінені файли в репозиторії (Upload files з тими самими назвами).
2. У `sw.js` збільште версію: `const VERSION = 'opora-1.0.1';`.
3. Відкрийте застосунок — з’явиться «Доступна нова версія → Оновити». Дані користувача при цьому не змінюються.

## Дані та резервні копії

- Налаштування (⚙︎) → «Створити резервну копію» → «Зберегти у Файли».
- «Перевірити резервну копію» — читає файл і показує, що в ньому, нічого не змінюючи.
- «Відновити з копії» — замінює поточні дані; одразу після цього можна натиснути «Повернути».
- Якщо видалити іконку з початкового екрана, iOS видалить і дані. Робіть копію хоча б раз на тиждень — застосунок підсвічує, коли копія застаріла.

## Нагадування

Вебзастосунок на GitHub Pages не може надсилати сповіщення, коли закритий, — для цього потрібен окремий сервер (Web Push), його в цій версії немає. Простий спосіб не проспати:

«Команди» → «Автоматизація» → «+» → «Час доби» (ваш час підйому) → «Запускати одразу» → дія «Показати сповіщення» з текстом «Відкрий ОПОРА».

Відкривайте застосунок з іконки: посилання з «Команд» відкривається в Safari, де інше сховище.

## Перевірка і тести

- На iPhone: відкрийте `https://ВАШ-ЛОГІН.github.io/opora/tests.html` — тести запустяться в Safari.
- На комп’ютері: `node tests.js` (Node 18+) або `npm test`.
- Локальний запуск: `python3 -m http.server 8080` у папці проєкту → `http://localhost:8080`.

## Безпека

- Політика CSP дозволяє лише власні файли: жодних зовнішніх скриптів, шрифтів і запитів.
- Service Worker кешує тільки файли застосунку; особисті дані в кеш не потрапляють.
- Текст справ екранується перед показом, імпорт перевіряє й очищає дані.
- Час рахується за поясом Europe/Kyiv незалежно від налаштувань пристрою.

## Далі

Наступні частини ОПОРА — режими дня, «Майно», «Швидко», «Сервіси» — додаватимуться в цей самий проєкт. Схема даних має версію (`v: 1`) і перевірку при завантаженні, тож оновлення не зітруть уже збережене.
